# LinePay Android

Android is intentionally **not implemented yet**.

When demand justifies it, build this client with native Kotlin + Jetpack Compose and make it conform to the same platform-neutral fixtures under `shared/contracts/`.

Do not copy iOS persistence/UI architecture mechanically. Copy the **product behavior and correctness contracts**, then use idiomatic Android APIs.

Before starting Android, require evidence such as a meaningful share of qualified prospects/users explicitly blocked by lack of Android. The second client should be earned by demand, not by symmetry.
